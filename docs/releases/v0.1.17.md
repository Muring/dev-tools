# dev-tools 0.1.17

설치 완료 화면에서 사용할 스킬을 선택하고 실행환경을 단계별로 준비할 수 있습니다.

- 블로그 초안: 저장소 탐색·선택, 인증값 안내·입력과 `.env` 생성, DB·이미지 저장소 연결 확인을 제공합니다. 기존 인증값 교체는 별도 동의를 받습니다.
- 사용량 분석: 로컬 기록 준비, Git 동기화·자동 기록·보고서 전송을 구분해 선택합니다. 초기 로컬 수집은 외부 발행을 호출하지 않습니다.
- 저장공간 진단: Ubuntu·Windows 진단 위치와 보존 위치를 직접 지정하고 읽기 전용 진단 결과를 열 수 있습니다. 자동 삭제는 실행하지 않습니다.
- 입력 → 변경 확인 → 결과를 같은 화면에서 전환합니다. 실패·대기·성공을 색상과 문구로 구분하며, 설정 수정 시 입력을 유지합니다.
- 작은 설치 창에서 제목과 버튼을 고정하고 본문만 스크롤하도록 정리했습니다. 경로 선택·접기·드롭다운·포커스 표시를 개선했습니다.
- 각 스킬의 초기 설정 가이드와 준비 상태 확인을 추가했습니다. 공용 Shopify PDP 명령은 제거했습니다.

## 사용 방법

새 PC는 `dev-tools-0.1.17-x64.exe`를 Windows 로컬 폴더에서 실행하고 **환경 확인 → 설치 구성 → 설치 진행 → 로그인·연동 → 설치 완료** 순서로 진행하세요.
완료 화면의 실행환경 준비는 선택 사항입니다. 사용할 스킬만 선택하고 변경 내용을 확인한 뒤 실행합니다.
기존 PC도 새 EXE로 환경을 확인하고 기존 설치 상태에 맞춰 진행할 수 있습니다. 공용 스킬만 갱신하려면 **커맨드 · 스킬 업데이트**를 사용하세요.
공용 스킬은 확인한 GitHub 콘텐츠 버전에서 설치하므로 스킬 설치와 실행환경 준비는 별도입니다.
실패하면 **로그 폴더 열기**를 사용하세요. 상태·로그는 `%LOCALAPPDATA%\dev-bootstrap`에 저장됩니다. 후속 버전은 GitHub Releases에서 받습니다.

## 검증과 한계

앱 형식·단위 16개·UI 15개 검사, 블로그 연결 4개·준비 상태 4개·환경 준비 25개·사용량 추적 67개·콘텐츠 업데이트 10개 검사와 설치 순서·셸·KB 검사가 통과했습니다. 패키징 리소스 52개와 소스의 일치도 확인했습니다.
최종 0.1.17 EXE를 Windows 로컬 격리 환경에서 실행해 버전 표시·preload IPC·실제 WSL 검사·GitHub 콘텐츠 조회·Windows 경로 준비 계획·완료 화면 검사가 통과했습니다. 화면 버전은 패키지 버전과 자동으로 일치하도록 수정했습니다.
Windows 호스트·WSL 위치·임시 예약 감시·저장공간 네이티브 검사는 이번 변경 소스에서 통과했습니다.

신규 Windows 전체 설치·재부팅·새 계정 인증, 실제 계정의 블로그 연결과 자동 예약 활성화는 미검증입니다. 서명되지 않은 Windows x64 Pre-release입니다.
