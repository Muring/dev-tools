# dev-tools 0.1.16

공용 작업 도우미와 스킬 지침을 업데이트했습니다.

- `usage-report`에 `bounded_run.py`를 추가했습니다. 큰 비대화형 명령을 한 번 실행하고 전체 출력은 비공개 로컬 로그에 보존하며, 기본 응답에는 종료코드·시간·로그 크기·경로만 표시합니다. 필요한 경우에만 제한된 원문 끝부분을 요청할 수 있습니다.
- 모델·추론 수준과 필수 검증을 유지하면서 중복 읽기와 짧은 반복 대기를 줄이는 공용 지침을 보완했습니다. 도구 호출을 강제로 가로채거나 토큰 절감률을 보장하지는 않습니다.
- 독립된 연재 초안을 병렬 작성할 때 편별 범위·근거를 먼저 정하고, 책임 에이전트가 통합 검토한 뒤 등록하도록 `blog-draft` 절차를 보완했습니다.
- 사용량 추적 문서를 현재 Git 기반 일일 발행·예약 동작에 맞췄습니다.

## 사용 방법

새 PC는 `dev-tools-0.1.16-x64.exe`를 Windows 로컬 폴더에서 실행하고 **환경 확인 → 설치 구성 → 설치 진행** 순서로 진행하세요.
기존 PC는 설치기의 **커맨드 · 스킬 업데이트 → 업데이트 확인 → 확인한 버전 적용**으로 공용 스킬을 갱신할 수 있습니다. 이번 스킬 변경은 0.1.15 설치기로도 받을 수 있습니다.

공용 스킬은 EXE에 복사해 넣지 않고 확인한 GitHub 콘텐츠 버전에서 설치합니다. 개인 로컬 전역 지침에 적용한 자동 진입 규칙은 이 EXE 실행만으로 다른 기기에 설치되지 않습니다.
기존 설정·백업·설치 경로를 유지하며 이전 릴리스 파일은 교체하지 않습니다.
실패하면 **로그 폴더 열기**에서 기록을 확인하세요. 상태·로그 경로는 `%LOCALAPPDATA%\dev-bootstrap`입니다. 후속 버전은 GitHub Releases에서 새 EXE를 받습니다.

## 검증과 한계

- 같은 세션의 효율화 도우미 합성 6개 검사와 Codex·Claude 공용 원본 연결 검증 결과를 재사용했습니다. 성공·실패 종료코드, 큰 출력의 로그 보존, argv·셸 파이프 의미와 POSIX 신호 종료를 확인했습니다.
- 변경되지 않은 앱 단위 15개·전체 UI 15개 검사는 앞서 통과한 결과를 재사용합니다. 이번 버전의 콘텐츠 업데이트 10개·형식·빌드·브랜드 표시 검사가 통과했습니다. 패키지 버전과 리소스 47개의 소스 일치를 확인했습니다.
- 최종 EXE를 Windows 로컬 격리 폴더에서 실행해 버전 0.1.16, sandbox preload·IPC, 실제 WSL 조회, GitHub 콘텐츠 미리보기와 설치 구성 화면 검사가 통과했습니다.
- 비밀값 자동 마스킹이나 전체 로그 용량 제한은 제공하지 않습니다. 대화형/TTY·상시 서버에는 도우미를 사용하지 않습니다.

신규 Windows 전체 설치·재부팅·인증은 미검증입니다. 서명되지 않은 Windows x64 Pre-release입니다.
