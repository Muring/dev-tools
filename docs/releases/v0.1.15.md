# dev-tools 0.1.15

개발환경 설치와 공용 도구 관리 역할에 맞춰 MuRing Dev Setup의 이름을 **dev-tools**로 변경했습니다.

- 설치 프로그램 좌측 상단과 창 제목을 `dev-tools`로 표시합니다. 최소 창 크기에서도 브랜드가 두 줄로 나뉘지 않습니다.
- EXE 이름은 `dev-tools-0.1.15-x64.exe`, 저장소는 `Muring/dev-tools`입니다. 설치·콘텐츠 업데이트의 원본 주소도 변경했습니다.
- 기존 설정·백업·설치 경로와 공용 스킬 연결은 유지합니다. 이전 릴리스 파일은 교체하지 않습니다.

## 사용 방법

EXE를 Windows 로컬 폴더에서 실행하고 **환경 확인 → 설치 구성 → 설치 진행** 순서로 진행합니다.
기존 PC에서는 새 EXE를 실행해 필요한 항목만 선택하세요. 기존 Ubuntu나 개발환경을 삭제할 필요가 없습니다.
실패하면 **로그 폴더 열기**에서 기록을 확인하고 미완료 단계를 재시도하세요.
Windows 상태·로그 경로는 `%LOCALAPPDATA%\dev-bootstrap`을 유지합니다.
후속 버전은 GitHub Releases에서 새 EXE를 받습니다.

## 검증과 한계

- 같은 세션에서 통과한 앱 단위 15개·전체 UI 15개·콘텐츠 업데이트 10개 검사 결과를 재사용했습니다.
- 버전 증가 후 형식 검사, 앱 빌드, 최소 창 크기의 브랜드 UI 검사와 Windows portable 패키징을 수행했습니다.
- 설치 순서·셸 설정·KB 설치 연결 검사가 통과했습니다.
- 패키지 내부 버전·창 제목·화면 버전 표시를 확인했습니다.
- Windows의 격리된 로컬 폴더에서 최종 EXE를 실행해 이름·버전, sandbox preload·IPC, 실제 WSL 조회, GitHub 콘텐츠 미리보기와 설치 구성 화면 검사가 통과했습니다. 새 브랜드의 한 줄 표시를 실제 화면에서도 확인했습니다.
- 동봉 리소스 47개가 소스와 일치하며, Windows 호스트·WSL 설치 경로 검사도 통과했습니다.

신규 Windows 전체 설치·재부팅·인증은 검증하지 않았습니다. 서명되지 않은 Windows x64 Pre-release입니다.
